# Which tests cover which files, for tools/affected-tests.

# One line per path: <path or path prefix> <test names...>
# The longest matching path wins. "ALL" stands for every test. A path that
# no line matches is covered by no test (documentation, the app's main.cpp):
# nothing runs for it locally; CI runs the full suite on every push.
#
# Built from the real includes and links (tests/CMakeLists.txt,
# src/CMakeLists.txt): a test covers a file when the test includes it, or
# links a library whose sources include it.
#   appbrowser    tst_browserlogic tst_extractors
#   applookup     tst_lookup tst_matching tst_lookupstore
#   appui         tst_ui tst_sellerpaging (appui uses every other library)
#   appplugins    tst_plugins
#   appmodel      tst_model
#   appsellerlist tst_sellerlist
# Tests labelled "browser" (tests/CMakeLists.txt) run only when a file under
# src/browser/ changed.
